# Lorenzo Gallone · Portfolio

Personal site of Lorenzo Gallone, full-stack engineer. Home page, three case studies
(Zitto e Corri, TIGER, Fanta F1), experience, education and contacts.

Stack: Next.js 16 (App Router, fully static), React 19, Tailwind CSS 4, TypeScript.
No backend and no client-side JavaScript beyond what Next.js ships.

## Run locally

```bash
npm install
npm run dev
```

Checks: `npm run lint`, `npm run typecheck`, `npm run build`.

## Editing content

All copy lives in [`lib/content.ts`](lib/content.ts): profile, projects (one entry
per case study, rendered at `/work/<slug>`), experience, education and skills.
Components in `components/` only lay it out.

The canonical URL comes from `NEXT_PUBLIC_SITE_URL` (it falls back to the current
Vercel address). Set it on Vercel when the domain changes.

## Design

Dark navy gradient (`#0a1020` → `#121f3d`), teal accent `#5eead4`, light blue
`#93c5fd`, system sans font and a node-graph motif, matching the LinkedIn banner.
Tokens are defined in `app/globals.css`. The Open Graph image is generated by
`app/opengraph-image.tsx`.
